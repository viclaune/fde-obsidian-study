Utilizado para permitir a busca de documentos similares à pergunta do usuário e assim criar contexto para que o [[LLMs]] possa emitir respostas melhores.

O Banco Vetorial são ideais para gerenciar grandes volumes de dados não estruturados, como texto, imagens e vídeos. Permite buscas baseadas em similaridade semântica, onde é possível encontrar informações contextualmente relacionadas, mesmo que não haja correspondência exata de termos. 

É projeto para lidar com grandes volumes de dados e consultas de baixa latência, garantindo desempenho eficiente mesmo em aplicações em larga escala.
