- Fine-Tuning resolve a limitação e problemas de uma LLM padrão.
- Ajusta um modelo de linguagem pré-treinado para tarefas específicas, refinando seus pesos com um conjunto de dados adicional.
- O fine-tuning é realizado quando:
	1. O modelo precisa melhorar o desempenho em uma aplicação específica;
	2. Uso de prompt engineering não é suficiente para obter respostas adequadas;
	3. Há necessidades de reduzir alucinações dentro de um domínio restrito;
	4. Deseja-se adaptar o modelo a uma linguagem técnica ou a um estilo de escrita específico;
	
- ==🟢O fine-tuning é um processo demorado e que possui um certo nível de complexidade, depende de forte conhecimento técnico do modelo de Deep Learning para então aplicar uma de muitas estratégias para aplica-lo==.
	- Sem garantia de bons resultados.
- Desvantagens do fine-tuning:
	1. Alto custo operacional;
	2. Necessidade de dados de qualidade;
	3. Risco de Overfitting;
	4. Tempo de treinamento elevado;
	5. Dificuldade de atualização;
	6. Perda de versatilidade;
